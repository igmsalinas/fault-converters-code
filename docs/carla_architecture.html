Fig. 1. Architecture of the proposed CARLA physics-informed anomaly detection framework. During self-supervised training, anchor sweeps \(X\), tolerance views \(X^+\), and transfer-function-perturbed hard negatives \(\tilde{X}\) are encoded by a shared universal backbone \(f_\theta\) and regularized by dual heads: a reconstruction decoder (\(\mathcal{L}_{\text{recon}}\)) and a hyperspherical contrastive projection head (\(\mathcal{L}_{\text{NCE}}\)). At edge inference time, the decoder branch is completely discarded, executing only \(f_\theta + h_\phi\) in \(0.34\,\text{ms}\) on the NVIDIA Jetson Nano.
1
Physics Hard-Negative Generation

Perturbs exact small-signal transfer function \(G_{vd}(s)\) rather than arbitrary noise:

\(G_{vd}(s) = \frac{V_g}{1 + s\left(\frac{L}{R} + (R_L + R_C)C\right) + s^2 L C}\)
  • \(C_{\text{out}}\) degradation: Shifts corner resonance \(f_0 = \frac{1}{2\pi\sqrt{LC}} \uparrow\)
  • \(ESR_C\) degradation: Moves ESR zero \(f_z = \frac{1}{2\pi R_C C} \downarrow\)
  • Sampling: Latin Hypercube sampling across distinct fault bands.
2
Multi-Task Contrastive Loss

Joint objective balances unperturbed reconstruction with hyperspherical repulsion:

\(\mathcal{L}_{\text{total}} = w_r \mathcal{L}_{\text{recon}} + w_c \mathcal{L}_{\text{NCE}}\)
  • \(\mathcal{L}_{\text{recon}}\) prevents representation collapse on healthy inputs.
  • \(\mathcal{L}_{\text{NCE}}\) pushes physical hard negatives away from nominal clusters.
  • Temperature \(\tau = 0.1\) controls cluster boundary sharpness.
3
Sub-Millisecond Edge Scoring

Non-parametric \(k\)-NN distance against nominal reference bank \(B = \{b_j\}_{j=1}^M\):

\(\text{Score}(x) = \frac{1}{k} \sum_{j \in \text{NN}_k(p(x))} \|p(x) - b_j\|_2\)
  • Fixed bank \(B\) of \(M=50\) precomputed nominal projections.
  • Decision threshold \(\tau\) calibrated on validation set for target false alarm rate.
  • Optimized via TensorRT FP16 on Jetson Nano embedded GPU.
